Nu Udra Gamma Set in Monster Hunter Wilds (MHWilds) is an Armor Set. Sets are comprised of five different pieces and can be complemented with other pieces of equipment. An armor set and its pieces contain special effects when equipped, and combine Skills depending on the pieces equipped.

Nu Udra Gamma Set Information in Monster Hunter Wilds

  • Nu Udra Gamma Set is a High rank Armor Set
  • Derived from Arch-Tempered Nu Udra monster
  • Stronger Element: Fire
  • Weakest Element: Water
  • 'Armor Set Variation: 'Nu Udra Alpha Set, Nu Udra Beta Set

Nu Udra Gamma Set can be crafted using the following Materials:

  • 60,000 Zenny
  • Nu Udra Hide + x13
  • Nu Udra Spike + x9
  • Nu Udra Oilmucus + x8
  • Nu Udra Tentacle + x5
  • Nu Udra Certificate Gamma x5
  • Firecell Stone x2
  • Nu Udra Horn + x2
  • Beast Gem x2
  • Nu Udra Flamegem x2
  • Nu Udra Cerebrospinal Fluid x2

Equipment Skills

Represent the skills provided by each piece of armor in the set.

Burst Lv5
Counterstrike Lv3
Resentment Lv5
Ambush Lv1
Speed Eating Lv3

Set Bonus Skills

They are skills that activate once 2 or 4 pieces of armor from the same Armor Set are equipped.

Nu Udra's Mutiny

x2 Bad Blood I
x4 Bad Blood II

Groups Skills

Works similarly to Set Bonus Skills, but instead of equipping armor pieces of the same set to activate it, you have to equip armor pieces that possess the same Group Skill, even if they belong to different Armor Sets. 3 equipped armor pieces sharing the same Group Skill are required to trigger it.

Lord's Soul

X3 Guts (Tenacity)
