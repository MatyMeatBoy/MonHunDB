Omega Attire Alpha Set in Monster Hunter Wilds (MHWilds) is an Armor Set. It can be obtained after completing the Planetes Protocol (Savage) Event Quest. Sets are comprised of five different pieces and can be complemented with other pieces of equipment. Like all armor sets, it is comprised of five pieces and can be complemented with other equipment. The set is strongest against Fire but is weakest against Thunder and Dragon. An armor set and its pieces contain special effects when equipped, and combine Skills depending on the pieces equipped.

MH Wilds Omega Attire Alpha Set Information

  • Omega Attire Alpha Set is a High Rank Armor Set
  • Stronger Element: Fire
  • Weakest Element: Thunder and Dragon
  • Armor Set Variation: --

How to Obtain Omega Attire Alpha Set in MH Wilds

Derived from the Savage version of Omega Planetes monster, the Omega attire Armor Set can be forged by completing the Planetes Protocol (Savage) Event Quest. This quest is unlocked after reaching Hunter Rank 100 and is accessible through the Final Fantasy XIV collaboration event.'

Omega Attire Alpha Set can be crafted using the following Materials:

  • 60000z
  • Lagiacrus Sapphire x1
  • Arkveld Gem x1
  • Faux Whitegleam Orb ×1
  • Mizutsune Water Orb x1
  • Seregios Dissenter x1
  • Omega Screw ×18
  • Omega Pedal ×3
  • Omega Data 2.0 ×3
  • Omega Data 1.0 x2
  • Omega Spring x14
  • Omega Nodule x2
  • Omega Lens x3
  • Omega Axle x3

Equipment Skills

Represent the skills provided by each individual piece of armor in the set.
  • Divine Blessing Lv3
  • Weakness Exploit Lv1
  • Partbreaker Lv2
  • Agitator Lv1
  • Burst Lv1
  • Evade Window Lv2

Set Bonus Skills

They are skills that activated once 2 or 4 pieces of Armor of the same Armor Set are equipped.

Omega Resonance

  • x2 Resonance I
  • x4 Resonance II

Groups Skills

Work similarly to Set Bonus Skills, but instead of equipping armor pieces of the same set to activate it, you have to equip armor pieces that possess the same Group Skill, even if they belong to different Armor Sets. 3 equipped armor pieces sharing the same Group Skill are required to trigger it.
