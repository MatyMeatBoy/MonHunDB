Azure Age Alpha Set in Monster Hunter Wilds (MHWilds) is an Armor Set. Sets are comprised of five different pieces and can be complemented with other pieces of equipment. An armor set and its pieces contain special effects when equipped, and combine Skills depending on the pieces equipped.

Azure Age Alpha Set Information in Monster Hunter Wilds

  • Azure Age Alpha Set is a High Rank Armor Set
  • Unlocked by completing the USJ collab event quest A Flash of Brilliance
  • Stronger Element: Water
  • Weakest Element: Thunder / Ice

Azure Age Alpha Set can be crafted using the following Materials:

  • 40000z
  • Azure Stargem x5
  • Rey Dau Scale + x6
  • Lagiacrus Hide + x4
  • Lagiacrus Sapphire x1
  • Rey Dau Carapace x5
  • Lagiacrus Scale + x5
  • Lagiacrus Horn + x3
  • Rey Dau Bolthorn x3
  • Rey Dau Fulgurtalon x4
  • Lagiacrus Tail x2
  • Rey Dau Boltgem x1
  • Rey Dau Tail x2
  • Lagiacrus Claw + x4
  • Lagiacrus Shockspike x3

Equipment Skills

Represent the skills provided by each individual piece of armor in the set.

  • Latent Power Lv5
  • Constitution Lv5
  • Adrenaline Rush Lv5
  • Quick Sheathe Lv3

Set Bonus Skills

They are skills that activated once 2 or 4 pieces of Armor of the same Armor Set are equipped.

Leviathan's Fury

x2 Azure Bolt I
x4 Azure Bolt II

Groups Skills

Work similarly to Set Bonus Skills, but instead of equipping armor pieces of the same set to activate it, you have to equip armor pieces that possess the same Group Skill, even if they belong to different Armor Sets. 3 equipped armor pieces sharing the same Group Skill are required to trigger it.

Fortifying Pelt

x3 Fortify
