Doshaguma Set in Monster Hunter Wilds (MHWilds) is an Armor Set. Sets are comprised of five different pieces and can be complemented with other pieces of equipment. An armor set and its pieces contain special effects when equipped, and combine Skills depending on the pieces equipped.

Doshaguma Set Information in Monster Hunter Wilds

  • Doshaguma Set is a Low Rank Armor Set
  • Derived from Doshaguma monster
  • Stronger Element: Dragon
  • Weakest Element: Fire
  • Armor Set Variation: Doshaguma Alpha Set (HR) and Doshaguma Beta Set (HR)

Doshaguma Set can be crafted using the following Materials:

  • 2000z
  • Doshaguma Hide x4
  • Doshaguma Fang x4
  • Doshaguma Claw x3
  • Sturdy Bone x1
  • Doshaguma Certificate x1
  • Doshaguma Fur x6
  • Brute Bone x1
  • Herbivore Shell x1

Equipment Skills

Represent the skills provided by each individual piece of armor in the set.

  • Free Meal Lv3
  • Recovery Speed Lv1

Set Bonus Skills

They are skills that activated once 2 or 4 pieces of Armor of the same Armor Set are equipped.

Doshaguma's Might

x2 Powerhouse I
x4 Powerhouse II

Groups Skills

Work similarly to Set Bonus Skills, but instead of equipping armor pieces of the same set to activate it, you have to equip armor pieces that possess the same Group Skill, even if they belong to different Armor Sets. 3 equipped armor pieces sharing the same Group Skill are required to trigger it.

Fortifying Pelt

x3 Fortify
